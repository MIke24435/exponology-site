# Exponology

Home for the web apps built under exponology.com.

Structure:

- `apps/<app-slug>/` — one folder per app: the app itself plus its landing page.
- `apps/mah-jongg-hand-finder/` — Mah Jongg Hand Finder (first app).

Deploys are driven from this repo on Cloudflare (push to `main` deploys).
Nothing goes live except through a push approved by Mike.
