How to use Mah Jongg Hand Finder

  1. 1Section & suits. Pick a card section and a number of suits, or leave either on “Any”.
  2. 2Numbers. Tap the numbers a hand must contain. Every number you turn on must be in the hand.
  3. 3Points. Tap one or more point values. A hand must be worth one of them.
  4. 4Must have. Turn on Flowers, Dragons or Winds, and Pairs, Pongs, Kongs or Quints — a hand must have every one you turn on.
  5. 5Tap Apply. The matching hands appear below. Tap Clear all to start again. If nothing matches, turn one filter off and try again.

How to read the hands

Example hand card
Hand ID — e.g. E2.2The letter is the section; the numbers pick out that hand in the Finder. It is not a code on the printed card.
SectionThe card family, right under the ID — here E, Consecutive Run. The note under the hand adds limits like “any 2 suits”.
Points — gold badgeWhat the hand scores, e.g. 25 pts. The Points filter keeps only the values you tap.
X / C badgeX · Exposed can be played with calls. C · Concealed must stay hidden — no calls, except for the winning tile.
SuitsThe tag says how many suits the hand uses, 0–3. In the notation, each bracket type is a different suit: ( ), [ ] and { }.
Groups & tilesTags list what the hand contains: Flowers, Dragons, Winds, and groups — Pair 2, Pong 3, Kong 4, Quint 5 of a kind.
Letter notationF Flower · D Dragon · 0 soap, counts as a dragon · N E W S the four Winds. A repeated letter, aaaa, is one number you choose; different letters, a b c, run in sequence. NNNN is four North Winds, not any wind.
What the filters meanSection and suits narrow by kind; Numbers and must-haves must all be present; Points matches any one value you tap. Untouched filters don’t narrow anything.
